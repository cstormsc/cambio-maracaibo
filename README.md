# Cambio Maracaibo

Webapp para convertir entre dólares, euros y bolívares con las tasas BCV y paralelo (Binance P2P), más Zelle y PayPal como referencia.

- App: https://cstormsc.github.io/cambio-maracaibo/
- Las tasas están en `rates.json` y se actualizan con una tarea diaria.
- Se instala desde el navegador ("Agregar a pantalla de inicio") y funciona sin conexión con las últimas tasas guardadas.

Las tasas son referenciales; confírmalas en bcv.org.ve antes de cambiar dinero.
